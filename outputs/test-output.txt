KNOWN LIMITATIONS OBSERVED WHILE PRODUCING THIS OUTPUT

1. Q1.C5 is marked 0 where the error key expects 1.
   The key itself names Q1.C5 as genuinely arguable: the answer is well laid
   out but contains a contradictory claim, so "clear, logically structured
   explanation" is defensible either way. The accuracy test deliberately does
   not assert Q1.C5 for this reason. Across six real runs it came back 1 twice
   and 0 four times.

2. Confidence is not well calibrated.
   Values cluster at 0.90-1.00 even on criteria the key calls arguable. The
   prompt was revised once to anchor confidence to observable conditions rather
   than a feeling, which spread the values from a flat 1.00 down to 0.90-1.00
   but did not push the arguable criteria below 0.9. As a result the overall
   confidence stays around 0.95 and the review flag does not fire on a run
   where the marking is in fact uncertain. Enforcement cannot compensate: it
   only lowers confidence when it has had to correct something, and on a clean
   run there is nothing to correct.

3. Q2.C1 scored 0 in one run out of six, taking the total to 7.
   The stated reason was "the student presents contradictory positions in the
   introduction and conclusion" — that is the Q2.C5 error being counted against
   Q2.C1 as well, which the prompt's independence rule forbids. It is not the
   failure the error key warns about most (the contrarian position was still
   credited in every run), but it is criterion bleed, and it puts the total one
   mark below the 8-10 band when it happens. The accuracy test asserts
   Q2.C1-C4 score 1, so it will fail on such a run rather than hide it.
